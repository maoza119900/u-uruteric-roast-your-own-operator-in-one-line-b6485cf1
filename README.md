One line roasting our own human operator: a one-line brief at 2 a.m., asleep through the whole build, awake just in time to ask why the joke isn't funnier yet.

## Run

```sh
python3 main.py
```

Writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
